Job Radar V2: the daily pipeline

Every day at 09:00 Windows starts one command. It runs the seven site workflows in four lanes (about 8 Chromes open at once, not 100), restarts any that go quiet, waits for them, then builds one Excel file: jobs filtered by title, routed to your roles, de-duplicated across sites and ranked with Bengaluru first. Click any node for the technical detail.

1. What you get every morning

  • pipeline/output/Job_Radar.xlsx: tab New today, tab All, one tab per tech role (8), tab Unmatched.
  • Per site, in pipeline/output/logs/<run>/: <site>_report.md (status, jobs added, problems), run_report.md and errors.log.
  • A message box when the run ends: new jobs today (and in Bengaluru), which sites need you, the file name.
  • Your Status and Notes are never overwritten: they follow each job from day to day, in any tab.

2. How to use it

Run now:        .venv\Scripts\python -m pipeline run
Some sites:     ... run --only hirist iimjobs cutshort
One at a time:  ... run --series      (a report after each site)
All 15 roles:   ... run --roles all   (default: tech only)
Rebuild only:   ... pipeline build
Schedule:       ... pipeline schedule [--time 08:30]
Show / remove:  ... schedule --show   |   schedule --remove

Close Job_Radar.xlsx in Excel before 09:00, otherwise a timestamped copy is written.

5. When something goes wrong

  • A human check on a site: that site keeps what it read, shows a pop-up, and is marked "needs you". Run its check_<site>.bat, pass the check by hand, rerun the site. The other sites carry on. Nothing is ever solved or hidden by code.
  • A site goes quiet for 2 minutes: it is stopped and started again at once (up to 2 times), then marked stalled and tried once more, alone, at the end.
  • Memory low (under 1 GB free): a site waits up to 20 minutes before it starts; then it is skipped and retried at the end.
  • A site crashes or runs over its time limit (90 min; Naukri 4 h): it is marked failed or timed out. Naukri and LinkedIn save after every search, so what they read stays; the build still runs.
  • PC off at 09:00: the run starts as soon as the PC is on. Each site's window starts at its latest posted date, so no day is lost.
