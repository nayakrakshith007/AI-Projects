How to run it (click to hide or show)

1. From this page

  • Run daily sources: the sources that run every day. Fast ones take about 1 minute, with the job boards about 40.
  • Run everything: all working sources (about 45 minutes with the job boards).
  • Untick Include job boards to skip the Chrome-based boards (LinkedIn, Naukri, Indeed...). Then a run takes about 9 minutes and opens no windows.
  • Re-run one source from the Sources or Problems tab.
  • Closing this page does not stop a run. Stop does.

Good to know: a job board that hits a human check shows needs you: pass the check in its Chrome window by hand, then re-run just that board (nothing is ever solved for you).
