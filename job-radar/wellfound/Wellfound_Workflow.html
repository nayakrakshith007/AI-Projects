Wellfound workflow (tech roles)

Reads Wellfound's public role pages with a pool of real Chromes that share one queue of pages. Wellfound has no date filter and no date sort, so every page is read; then the one-week window, the India location rule and the experience rule are applied, and the jobs go into an Excel file. Click any node for the technical detail.

1. The input you give it

The shared file job-radar-V3/input.csv. Only tech roles run (Experience above 0).

Role,Keywords,Experience,Location
AI Engineer,"AI Engineer;LLM Engineer",5,India
  • Keywords become Wellfound role pages through wellfound/slugs.csv (keyword to role slug; - = no page). Several keywords can share one page.
  • Experience: Wellfound shows a minimum ("5 years of exp"), kept as "5+ years", which always passes the rule.
  • Command line: --role, --hours N (default automatic, at most 168 h = 7 days; 0 = no window), --workers N (Chromes, max 8), --keep-all-locations, --include-non-tech.

4. The location rule

  • Kept: India (a city or the India list), Remote - India, Remote - anywhere, and Remote - location not stated (a remote job with no place shown).
  • Dropped: remote jobs that name a place outside India (United States, Toronto, Tel Aviv ...). --keep-all-locations keeps them, marked "Outside India: place".
  • A Bengaluru column marks Bengaluru and Bangalore jobs so they can be ranked first later.
  • Matching uses common/geo.py: India, Indian states and about 80 city names.

5. What a real run gave (2026-10-11, 7-day window)

  • 8 tech roles, 14 keywords, 16 page lists (Forward Deployed Engineer and AI Architect have no Wellfound page). 8 Chromes sharing the page queue read 178 pages and 4,668 jobs in 7.9 minutes (the first version, one Chrome per role, took 18.9 minutes). Pages per Chrome: 20 to 24, evenly shared.
  • 220 unique jobs kept: India 127, Remote - anywhere 48, Remote - location not stated 25, Remote - India 20. Bengaluru: 62.
  • Dropped: 3,928 outside the week, 351 outside India (remote jobs naming another country), 0 by the experience rule.
  • Kept by role: AI Engineer 129, Data Analyst 37, Data Scientist 17, Architect 16, ML Engineer 14, Business Analyst 7 (the AI Engineer page also carries the LLM and Generative AI keywords and is broad).
  • To know: 92 of the 220 are labelled "1 week ago", which on Wellfound can mean 7 to 13 days. The ai-engineer remote list has 51 pages; the first version's 30-page ceiling had cut it off, so the ceiling is now Wellfound's own 100.
  • No human check appeared on any of the 178 pages.
