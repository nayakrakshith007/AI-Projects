Cutshort workflow (tech roles)

Reads Cutshort's public data science job lists (India, Bengaluru, remote) in one real Chrome. Each list page ships its newest 50 jobs as JSON inside the page, so no scrolling and no screen scraping are needed. Click any node for the technical detail.

Python 3.12 Playwright + installed Chrome, one window 3 public lists newest first, 50 jobs each BeautifulSoup + the page's JSON openpyxl Excel 0 Claude tokens $0 no login
Trigger / input Browser Logic Parse Storage Safety

1. The input you give it

Cutshort has broad categories, not one page per role, so the lists live in cutshort/lists.csv. input.csv only sets the experience rule (the lowest minimum of the tech roles, 5).

slug,label
datascience-jobs,Data Science (India)
datascience-jobs-in-bangalore-bengaluru,Data Science (Bengaluru)
remote-datascience-jobs,Data Science (Remote)
  • Command line: --hours N (default automatic, at most 168 h = 7 days), --input.
  • Role routing (which job is an AI Engineer, a Data Analyst ...) is done later, in the combined pipeline; the Role column stays empty here.

4. What Cutshort offers without a login

  • The personal link /profile/all-jobs?matchesfor=... needs a login (it redirects to the sign-up page), so it is not used.
  • Public category pages /jobs/<category>-jobs show the newest 50 jobs of a list, newest first. "Page 2" returns the same 50.
  • Only broad categories exist (data science, backend, DevOps ...). There is no page for machine learning, AI, analyst or architect roles.
  • The keyword search (/search-jobs) is ranked by relevance, matches loosely (3,948 hits for "machine learning engineer") and each response is about 20 MB, so it is not used.

5. What a real run gave (2026-10-11)

  • 3 pages, 150 jobs read in about 45 seconds. No human check.
  • 7-day window: 2 jobs. 30-day window: 9 jobs (India 9, Bengaluru 2 of which are also in India, remote 0). Cutshort adds only a few data science jobs a week.
  • 4 internships were dropped; the experience rule dropped none beyond that.
  • Each job has salary, experience range, skills, company size and stage, website and the full description (up to 7,600 characters here).

6. Not in this workflow (done later, in the combined pipeline)

  • Role routing and title filtering, and removing duplicates across all sites.
  • Roles outside data science (Business Analyst, Architect): Cutshort has no list for them.
  • The daily 9 AM schedule.
